This project uses a product dataset to practice essential Excel data‑analysis skills. The file includes tasks involving numerical calculations, logical functions, and text extraction.

Contents
Dataset Sheet: Contains product information such as Product ID, Name, Brand, Price, Quantity, and Category.
Task Sections: SUM, COUNT, AVERAGE, MIN, MAX, IF, SUMIF, COUNTIF, LEFT, RIGHT, MID.
What You Will Learn
Calculate totals, averages, and extremes in data.
Categorize values using conditional logic.
Perform criteria‑based analysis.
Extract structured text from coded fields.
Output
The completed sheet will display:

Total price, product count, average price.
Minimum and maximum prices.
Price Range classification.
Electronics total price and count of low‑priced items.
Extracted Day, Country Code, and Month fields.
